# 羊了个羊 (Sheep a Sheep) - React Clone

## 简介

一个基于 **React + TypeScript** 的高仿「羊了个羊」消除游戏，实现了多层叠牌、遮挡判定、道具系统以及移动端优先的自适应布局，并在浏览器中还原接近原版的视觉与交互体验。

## 立即试玩: 

[https://ylgy.fun/](https://ylgy.fun/) or [https://sheep-sheep-game.vercel.app/](https://sheep-sheep-game.vercel.app/)

## 核心功能

- **核心消除算法与卡牌堆叠逻辑**：  
  - 关卡通过模板生成多层网格布局，每张牌占用固定网格并带有 `z` 与 `layer` 概念。  
  - 槽位中三张相同图案的牌会被自动检测并消除。

- **复杂的 AABB 碰撞检测与遮挡判定**：  
  - 使用 AABB 逻辑检测上层牌与下层牌在 2×2 网格中的重叠关系。  
  - 仅当一张牌没有被上方任意一张未移除的牌遮挡时才可点击，模拟真实堆叠效果。

- **道具系统（移出、撤回、洗牌）**：  
  - **移出 (Pop Out)**：从槽位左侧移出 3 张牌，放入临时缓冲区，缓冲区的牌可再次点击回到槽位。  
  - **撤回 (Undo)**：撤回最近一次「未参与三消」的点击，将那张牌从槽位送回原始棋盘位置。  
  - **洗牌 (Shuffle)**：仅打乱棋盘上**剩余未消除且不在缓冲区**的牌的种类，保留原有布局坐标不变。

- **自适应布局与还原排版**：  
  - 使用 `w-screen / h-screen` + 视口尺寸计算缩放比，使棋盘在不同手机和桌面分辨率下都能完整展示。  
  - 棋盘居中放置于绿色卡片容器内，下方为槽位栏与三大功能按钮，整体布局接近原版。

- **顺滑的动画反馈（CSS 动画，可扩展为 Framer Motion）**：  
  - 牌从棋盘飞入槽位的飞行动画。  
  - 槽位插入 / 三消时的缩放、挤压与淡出动效。  
  - 洗牌时棋盘牌面的整体抖动动画。  
  - 游戏胜利 / 失败的覆盖层与弹窗动画（胜利弹出、失败轻微晃动）。  
  - 如需进一步升级，可在现有结构基础上接入 **Framer Motion** 以获得更丰富的物理与过渡效果。

## 技术栈

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS (v4)** – 原子化样式与响应式布局
- **Zustand** – 轻量级状态管理（卡牌状态、槽位、道具、历史记录等）
- **CSS Animations / Keyframes** – 飞行动画、三消动画、洗牌抖动与结束弹窗动效  
  （如有需要，可在此基础上引入 **Framer Motion** 进行升级）

## 本地开发与运行

> 项目实际前端代码位于 `game/` 目录，下列命令需在该目录中执行。

```bash
cd game
npm install
npm run dev
```

默认情况下，Vite 会在 `http://localhost:5173` 启动开发服务器。  
你可以使用浏览器的「移动设备模式」或在同一局域网的手机上访问该地址，体验完整的移动端效果。
